# Прямые зависимости бота, версии зафиксированы.

# Версии подобраны так, чтобы сборка в Docker была воспроизводимой:

# Клиент API MAX. Версия 1.2.2 — та, на которой бот проверен сквозным
# прогоном против боевого MAX: запуск, поллинг, 22 обработчика, запись
# клиента и уведомления. Форк max-messenger/max-botapi-python новее, но
# он не привязан к версии и требует git при сборке, поэтому в фиксированную
# сборку не включён. Переключиться на него — см. README, раздел «Зависимости».
maxapi==1.2.2

# Асинхронный SQLite. Поток в отдельном потоке — sqlite3 синхронный,
# и блокирующий вызов посреди event loop останавливал бы поллинг.
aiosqlite==0.22.1

# Настройки из .env и переменных окружения.
pydantic-settings==2.15.0

# База часовых поясов IANA для ZoneInfo. Нужна и в контейнере, и локально:
